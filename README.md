# 🏢 Коворкинг Booking API

Backend-часть дипломного проекта Нетологии (Python-разработчик). 
Сервис для управления и бронирования рабочих пространств в коворкинге.

## 🛠 Стек технологий
- Python 3.10+
- Django 4.x / 5.x
- Django REST Framework
- SQLite (для разработки)
- PyYAML, Requests

## 🚀 Быстрый старт

1. Клонируйте репозиторий:
   ```
   bash
   git clone https://github.com/nshvetsov03/diplom-project.git
   cd diplom-project
   ```
   
2. Создайте и активируйте виртуальное окружение:
  ```
   python -m venv .venv
   source .venv/Scripts/activate  # Для Windows
   # source .venv/bin/activate    # Для macOS/Linux
   ```

3. Установите зависимости
   ```pip install -r requirements.txt```
(Если файла нет, установите вручную: pip install django djangorestframework pyyaml requests)

4. Примените миграции:
   ```python manage.py migrate```

5. Запустите сервер разработки:
   ```python manage.py runserver```

## 📡 Основные API Endpoints

| Метод | Путь | Описание | Доступ |
|-------|------|----------|--------|
| POST | `/api/registration/` | Регистрация нового пользователя | Публичный |
| POST | `/api/login/` | Получение токена авторизации | Публичный |
| GET | `/api/spaces/` | Список доступных пространств | Публичный |
| GET | `/api/contacts/` | Список контактов пользователя | Только авторизованным |
| POST | `/api/contacts/` | Создание нового контакта | Только авторизованным |
| DELETE | `/api/contacts/<pk>/` | Удаление контакта | Только авторизованным |
| GET | `/api/basket/` | Просмотр текущей корзины | Только авторизованным |
| POST | `/api/basket/` | Добавление позиции в корзину | Только авторизованным |
| DELETE | `/api/basket/<pk>/` | Удаление позиции из корзины | Только авторизованным |
| POST | `/api/booking/<pk>/confirm/` | Подтверждение заказа (с Email) | Только авторизованным |
| GET | `/api/bookings/` | История заказов пользователя | Только авторизованным |
| POST | `/api/partner-update/` | Импорт прайса из YAML | Только для магазинов |

🧪 Автоматическое тестирование
Для проверки полного цикла работы API (регистрация → логин → корзина → подтверждение заказа) используйте
встроенный скрипт:
    ```python test_api.py```

*Примечание*: Отправка email настроена через *console.EmailBackend*, поэтому текст письма будет выведен
в консоль сервера при подтверждении заказа.

## ⚠️ Примечание по архитектуре (Domain Adaptation)
В исходном техническом задании описана логика маркетплейса с ролями "Поставщик" и "Покупатель", а также сущностью "Магазин" (`shop.state`). 
Поскольку данный проект реализует **сервис бронирования коворкинга**, данная логика была осознанно адаптирована под предметную область:
- Все пользователи являются арендаторами (роль "Покупатель").
- Функция обновления прайса (`PartnerUpdate`) доступна авторизованным пользователям для актуализации данных о пространствах.
- Понятие "отключения приема заказов магазином" заменено на актуальное наличие свободных мест (`free_seat`) в конкретном пространстве (`SpaceDetails`), что является более релевантным для коворкинга.
- Импорт YAML работает с привязкой к `Location` (локация коворкинга), что полностью закрывает потребность в обновлении данных без усложнения модели.
